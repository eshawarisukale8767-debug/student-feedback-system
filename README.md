# Student Feedback App

A simple full-stack student feedback application built using HTML, JavaScript, Python and Flask.

## Features

- Student name input
- Rating selection
- Feedback submission
- Flask REST API
- Frontend-backend communication

## Technologies Used

- HTML
- JavaScript
- Python
- Flask
- Flask-CORS
